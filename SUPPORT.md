# Support

Aagedal Data Revival is open-source software for recovering files from media
you own. It is provided without a guarantee that any file can be recovered.
Stop using a card as soon as data loss is discovered; new writes can overwrite
recoverable data.

## Getting help

Search existing reports or open an issue in the
[GitHub issue tracker](https://github.com/aagedal/Aagedal-Data-Revival/issues).
Include the app version, macOS version, Mac model, card type and capacity, the
step that failed, and the exact on-screen error. Never upload a card image,
recovered photos, or other private content to a public issue.

The `runner.log`, ddrescue log, mapfile, and `session.json` files can help with
diagnosis, but inspect them before sharing. Paths, device details, filenames,
and recovery metadata may identify you or reveal private information. Redact
anything sensitive and share only the smallest relevant excerpt.

## Safety and scope

- Work only with media you own or are authorized to recover.
- Keep the source card physically write-protected when its hardware supports it.
- Save card images, recovery output, and exports to a different physical device.
- Preserve the original card and the ddrescue mapfile until recovery is complete.
- Do not treat a preview or file extension as proof that a recovered file is
  complete.

Security-sensitive reports should not include exploit details in a public issue.
Contact the repository owner privately through the contact method listed on the
[GitHub profile](https://github.com/aagedal) before disclosing details.
